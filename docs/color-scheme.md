# Color Scheme Design Tokens

This file defines the color palette for the website, intended for use across the application.

| Variable Name | Color Hex | Description |
| :--- | :--- | :--- |
| --color-background | #FFFFFF | Primary background color (Light Mode default) |
| --color-secondary-background | #FFF8F0 | Secondary background or card background |
| --color-primary-text | #000000 | Main body text color |
| --color-secondary-text | #363636 | Subdued text, e.g., metadata |
| --color-highlight | #93140D | Primary accent or highlight color (e.g., links, required fields) |
